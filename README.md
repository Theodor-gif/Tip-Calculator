# Tip Calculator

I built this project to better understand JavaScript and to improve my problem-solving skills.

In this web application, the user can split a bill with friends and add a tip.
The app calculates how much each person needs to pay.

## Features

- Enter the number of people splitting the bill
- Enter the total bill amount
- Choose the tip amount (or percentage) you want to give
- See how much each person needs to pay

## Tech Stack

- HTML5
- CSS
- Vanilla JavaScript
